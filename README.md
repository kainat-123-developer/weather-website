# 🌦️ Weather Website

A responsive weather website that allows users to search for cities and view current weather information and a 7-day forecast.

## 📌 Project Overview

The Weather Website is a web-based application developed to provide users with weather information for different cities.

The application retrieves weather data from a weather API and dynamically displays:

- Current temperature
- Weather condition
- Weather icon
- Feels-like temperature
- Humidity
- Wind speed
- Last updated time
- 7-day weather forecast
- Celsius/Fahrenheit conversion

## 🎯 Objectives

The main objectives of this project are:

1. Build a functional weather website.
2. Practice HTML, CSS and JavaScript.
3. Learn how to work with REST APIs.
4. Implement dynamic data rendering.
5. Create a responsive user interface.
6. Practice Git and GitHub workflow.
7. Maintain proper software project documentation.

## ✨ Features

### 🔍 City Search

Users can enter a city name and search for its weather information.

### 🌡️ Current Weather

The application displays:

- Current temperature
- Weather condition
- Weather icon
- Feels-like temperature
- Humidity
- Wind speed

### 📅 7-Day Forecast

The application displays a 7-day forecast including:

- Day
- Date
- Weather condition
- Weather icon
- Maximum temperature
- Minimum temperature

### 🌡️ Temperature Conversion

Users can switch between:

- Celsius (°C)
- Fahrenheit (°F)

### 🕐 Last Updated

The application displays the time when the current weather data was retrieved.

### 📱 Responsive Design

The website adapts to:

- Desktop
- Tablet
- Mobile devices
