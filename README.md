# 🌦️ Weather Website

## Project Description

The Weather Website is a web-based application that allows users
to search for weather information by city.

The application will retrieve weather data from a weather API and
display current weather conditions and forecast information in a
simple and user-friendly interface.

## Features

- Search weather by city
- Display current temperature
- Display weather condition
- Display feels-like temperature
- Display humidity
- Display wind speed
- Display weather forecast
- Celsius/Fahrenheit conversion
- Loading indicator
- Error handling
- Responsive design

## Technologies

- HTML5
- CSS3
- JavaScript
- Weather API
- Git
- GitHub
